# /ads Command
Triggers the hormozi-ad-assembler skill.
When this command is used, immediately ask:
1. What is your product?
2. What platform? (Facebook, Instagram, TikTok, Pinterest, YouTube)
3. What is your prospect awareness level?
4. Do you have existing winning hooks or ads?
Then assemble a complete ad batch using the
50 Hooks x 3-5 Meats x 1-3 CTAs formula.
